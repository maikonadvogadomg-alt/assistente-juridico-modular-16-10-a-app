📑 Organizador de Documentos

Importa o PDF, mostra tudo organizado e numerado, e você cria o padrão para baixar no formato que quiser.

1. Documento

Toque numa linha de dado (ex.: uma competência com valor) para criar uma regra a partir dela.

Regras do padrão

As regras são testadas de cima para baixo, em cada linha. Ignorar tira cabeçalho/rodapé. Linha de dados vira um registro. Valor de cabeçalho (ex.: o órgão, o vínculo) vale para as linhas de dados que vêm depois.

Formato de saída

Escreva como cada linha deve sair. Use os campos entre chaves. Ex.: {competencia};{valor};{moeda}
